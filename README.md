# Client Video Hub

Je veux créer une application web privée de livraison de vidéos pour mon entreprise de vidéaste. L'application doit comporter deux rôles :

Un espace Administrateur (pour moi) : je peux créer un projet pour un client, uploader des liens vidéos (rushs ou montage final), voir les retours, et basculer un interrupteur 'Payé / Validé' qui débloquera le téléchargement pour le client.

Un espace Client (sécurisé par un accès) : le client arrive sur une interface à mon nom, peut voir ses projets, lire les vidéos dans un lecteur en streaming intégré (sans bouton de téléchargement, clic droit désactivé), laisser des commentaires et voir un bouton de téléchargement qui reste grisé/bloqué tant que je n'ai pas validé le paiement côté admin. Utilise React, Tailwind CSS et Supabase pour la base de données et l'authentification."*
